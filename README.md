# digital_marketing_analysis
Digital Marketing analysis is complete information about revenue, cost, watch time, season, year etc. Tools like POWER BI, MYSQL, CSV FILE, PYTHON.
OVERVIEW

  The project demonstrates an end-to-end data analytics workflow, from raw data ingestion to insights presentation. It covers data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis using MySQL, and visualization through an interactive dashboard. Final insights are documented in a written report and a presentation created using Gamma.

The goal of this project is to showcase practical data analytics skills commonly required in real-world business and analytics roles.
